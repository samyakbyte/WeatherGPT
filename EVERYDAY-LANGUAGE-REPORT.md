# Everyday-language repair pass

Scope: 100 authored everyday utterances, each tested against 100 weather states, giving 10,000 executions. This does NOT complete the requested 10,000 distinct natural-language questions. The previous structured date tests were insufficient evidence of conversational quality. This pass prioritizes concrete Hindi, Hinglish and English comprehension failures. No claim of broad generative understanding or model training is made.

Baseline: 7860 passed, 2140 failed, involving 43 distinct utterances. Final: 10,000 passed. These are fixed-data routing/content checks, not a human grade for every sentence. Each question is assigned an expected topic, relative day and response language. Rain replies must contain the fixture probability. Missing weather must not invent metric values. Tests also reject unwanted place extraction and failed interpretation. The 100 states vary rain probability from 0–99, with every tenth state using missing weather instead. Other weather values are held fixed. Question text and expectations did not change after the baseline.

Repairs: natural rain expressions (भीगना, soaked, get wet, chata, रेनकोट), parson, tomato/potato/irrigation vocabulary in Hindi/Hinglish, अम्लीय, natural sunrise/sunset questions and हवा का दबाव. Missing-weather replies now honor Hindi. Existing English, Hindi and prior test suites still pass. Hinglish input receives Hindi script where Hindi is detected or selected; Romanized Hindi output is not implemented.

Run `node tests/run-everyday-10000.js`. Read `tests/everyday-language.txt` for all 100 authored questions and `docs/EVERYDAY-10000-RESULTS.json` for the full results. The examples CSV contains four states per question for easier review. The complete CSV contains 10,000 rows. Earlier suites remain reproducible using their existing runners. No runtime dependency was added. This parser still uses rules and can fail on unfamiliar language, ambiguous conversation and compound requests; these 100 questions do not establish general conversational competence.
