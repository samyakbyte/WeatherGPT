# Weather scenes and natural-question batch

The question bank contains 10,000 distinct strings composed from 100 authored everyday English, Hindi and Hinglish cores, ten named cities and ten relative date/time windows. There are no duplicates within the bank or against the five earlier question files. This is compositional coverage, NOT 10,000 independently authored questions or unique intents. Repeated grammatical structures remain. It therefore does not meet an interpretation of the request that requires 10,000 independently written, non-template questions. Questions use today, tomorrow, the day after tomorrow, morning, afternoon, evening and night instead of ISO timestamps. Sources, generation code and every response are included.

Initial results: 9,370 passed, 630 failed. Final: 10,000 passed. The 630 failures exposed one trailing-comma place-cleaning defect; it is repaired. These checks test place/date/topic, Hindi output, fixture rain probability and absence of invalid values. They do not evaluate every sentence for clarity, exercise a real geocoder for each city, or prove robust general conversation. Existing 669 logic checks, prior banks and the 10,000 weather-state executions also pass. Browser suite: 249 passed, zero failed. Includes condition mapping, mobile overflow and reduced-motion checks. All weather figures in tests and screenshots are fixtures.

UI: six generated photographic scenes for sun, clouds, rain/storm, snow, fog and clear night. The hero follows the application's weather/day attributes, with a neutral unavailable state. Scene transitions crossfade. Layered shaded sun/moon and cloud volumes use CSS perspective and pointer movement. Rain/snow particles, existing Anime.js scroll reveals and cursor feedback supply lightweight motion. Continuous effects pause through the existing atmosphere pause/visibility controller; reduced motion disables tilt, particles and transitions. This is CSS depth, not a WebGL scene or video. No video downloads or new runtime libraries were added. Mobile particle count is limited.

Asset: assets/weather-scenes.webp, 123,762 bytes. Generated with the built-in image generation tool as a six-panel 3-by-2 photographic atlas, then converted to WebP. Decorative landscapes do not depict the selected real location. Prompt: six equal photographic panels, top row sunny daytime / overcast / rain, bottom row snow / fog / clear night; open landscapes with distant mountains and horizon in lower third; no people, buildings, text, logos or UI; cinematic natural photography and sharp tile boundaries. Original generated PNG retained outside the package. This is one atlas asset, not six separate downloads.

Design choices: retain existing dark blue information surfaces and typography; reserve dimensional visuals for the current-weather hero; apply a dark left-edge scrim for white text. Installed frontend-design guidance informed hierarchy and visual review, Anime.js guidance informed use of the existing engine, and the imagegen skill produced the bitmap. Other installed skills remain packaged; no additional skills or paid integrations were necessary.

Run node tests/run-natural-10000.js and the existing npm tests. The full project ZIP is complete. The patch overlays WeatherGPT-Mark-7-Everyday. No live performance score or universal error-free claim is made.
