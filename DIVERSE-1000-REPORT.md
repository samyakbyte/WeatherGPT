# WeatherGPT varied-question evaluation

The new corpus contains 1,000 distinct question texts across 40 categories, with 25 questions per category. Topics include college trips, weather readings, outdoor plans, spraying, irrigation, sowing, harvest readiness, pH availability and sample records, safety limits, app controls, incomplete data, comparisons, follow-ups, informal English and Hindi. Each question is stored explicitly in tests/diverse-1000-cases.json. The earlier city/time combination suite remains a separate regression check.

The initial audit flagged 304 cases. Fixes addressed mistaken locations, weather terms embedded in farm decisions, solar-relative times, requests for explanations being mistaken for commands, and unsupported medical, agricultural and external actions. Two test definitions were corrected during review. One follow-up explicitly names London. One UV question was made unambiguously a request for a definition. Additional content checks caught farm questions that still produced umbrella advice. Reviewing the recorded answers then exposed a compound question that answered rain but omitted wind. The app now uses the same forecast hours for both measures in that case.

All 1,000 final cases passed the automated checks with the optional NLP library enabled and disabled. Chrome also ran the 1,000 cases against the application interpreter and answer functions. The browser suite passed 203 checks including 40 chat-form submissions, one per new category, the previous 20 form questions, and a check that the compound forecast included both rain and wind. The logic suite passed 656 checks. The previous 1,000-scenario matrix also passed.

The automated checks cover selected-location preservation, relevant forecast topics, basic response content, unavailable data, explanations, unsupported capabilities and unintended actions. Dedicated numeric checks use distinctive hourly values to verify the selected time, including cloud cover at sunset and tomorrow’s wind and rain. The tests use synthetic provider data. Named-city fixtures exercise interpretation, while live provider accuracy and real device behavior were outside this evaluation.

A passing row means it met its automated contract. Some responses give general guidance, ask for clarification or explain a limitation. Some multipart questions still require separate requests. The cases were used during development and do not provide a blind estimate of performance on new questions. The CSV includes every response so answer quality can be reviewed independently.

To reproduce the new suite, run `npm run test:diverse`. For the earlier suite use `npm run test:assistant`. Run `npm test` for the logic checks and `npm run test:browser` with the documented browser dependencies for interface tests. Install the cumulative patch over the reworked Mark 7 project and hard-refresh the page, or extract the full project ZIP.
